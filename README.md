# Airbnb Prices in European Cities

Case study from my data analyst internship at Autonmis (2025). The data is the public Kaggle dataset "Airbnb Prices in European Cities".

**What I did:** combined the city and weekday/weekend files into one table with SQL, then analysed price by city, room type, distance from the centre and guest rating, and built a dashboard on the Autonmis platform.

**Files:** the dataset (zip), the dashboard and the case-study write-up (PDFs).
